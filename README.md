# Machine Learning Lab

A collection of Machine Learning laboratory experiments implemented using Python and Jupyter Notebook. This repository contains experiment-wise notebooks, algorithm implementations, and supporting materials for academic learning and practice.

## Technologies Used

* Python 3.x
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 


Launch Jupyter Notebook:

```bash
jupyter notebook
```
